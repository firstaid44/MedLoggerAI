การเชื่อมต่อ Google Sheet ยังไม่ตั้งค่า
วิธีตั้งค่า (ทำครั้งเดียว)
ฝั่ง Google Sheet:
1) เปิดชีต → ส่วนขยาย → Apps Script วางโค้ด med-logger.gs
2) Project Settings → Script Properties → เพิ่ม ANTHROPIC_API_KEY = คีย์ของคุณ
3) Deploy → เว็บแอป → ดำเนินการในนาม: ฉัน, เข้าถึง: ทุกคน → คัดลอก URL /exec
ฝั่งเว็บ (GitHub Pages): ดูขั้นตอนในไฟล์ README.md
เลือกจากคลังได้หลายรูปพร้อมกัน — ระบบจะให้ตรวจทานทีละรูป
